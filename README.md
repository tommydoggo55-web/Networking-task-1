# Networking-task-1
## Objective
To understand the fundamentals of computer networking and
analyze basic network information using practical commands.

## Topics Covered
- IP Address
- MAC Address
- Default Gateway
- DNS
- Network Communication
- Network Routing

## Commands Used
- ipconfig
- ping
- tracert

## Practical Work
I analyzed my device's network configuration and used
networking commands to understand how devices communicate
over a network.
